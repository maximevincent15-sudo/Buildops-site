Étiquettes QR code sur les extincteurs : le guide pour les mainteneurs

Sur un site de 300 extincteurs, retrouver le bon appareil, sa fiche et son historique fait perdre du temps à chaque visite. Le QR code sur l'étiquette règle ce problème… à condition de bien le choisir, de savoir quoi mettre dedans et de l'exploiter avec le bon outil. Voici ce qu'il faut savoir, sans jargon.

Pourquoi identifier chaque appareil

La maintenance des extincteurs se fait appareil par appareil : chaque extincteur a un numéro, un emplacement, une année de fabrication et un historique de vérifications. C'est ce suivi individuel qui alimente le registre de sécurité du client, et c'est lui qu'on vous demandera en cas de contrôle ou de sinistre.

Sur un petit site, un numéro écrit au feutre et un plan suffisent. Sur un site industriel, un hôpital ou un parc de plusieurs bâtiments, c'est une autre histoire :

  • le technicien cherche l'appareil dans une liste de plusieurs centaines de lignes ;
  • les numéros s'effacent, les appareils sont déplacés, les plans ne sont plus à jour ;
  • une erreur de saisie et le contrôle est enregistré sur le mauvais extincteur ;
  • à la fin de la journée, impossible de savoir avec certitude ce qui reste à contrôler.
À retenir — Le QR code n'est pas une obligation réglementaire. Ce qui est attendu, c'est que chaque appareil soit identifié et suivi. Le QR code est simplement le moyen le plus rapide et le plus fiable de le faire.

Ce que le QR code change sur le terrain

Avec une étiquette QR sur chaque appareil, la visite se résume à un geste : le technicien vise l'étiquette avec son téléphone, et la fiche de l'extincteur s'ouvre. Il fait son contrôle, enregistre, puis scanne le suivant.

Le gain est d'autant plus fort que le site est grand. Sur un parc de quelques milliers d'appareils, c'est souvent la différence entre une tournée maîtrisée et une journée passée à chercher.

Que mettre dans le QR code ?

C'est la question que se posent tous les mainteneurs au moment de commander leurs étiquettes. Trois options existent :

1. Un identifiant court (le plus courant)

Le QR code contient simplement le numéro de l'appareil, par exemple EXT-004512. C'est la solution la plus robuste : le code est petit, se lit de loin et reste lisible même un peu abîmé. Toutes les informations (type, marque, emplacement, historique) sont dans le logiciel, pas sur l'étiquette.

2. Les caractéristiques de l'appareil

Le QR code contient le numéro, le type, la marque et l'année, par exemple « N° : 0452 ; Type : EP6 ABC ; Marque : Sicli ; Année : 2019 ». Avantage : à la première visite, un bon logiciel peut remplir la fiche de l'appareil tout seul à partir du scan. Inconvénient : le code est plus dense, donc l'étiquette doit être un peu plus grande.

3. Un lien internet

Le QR code contient une adresse web propre à l'appareil. C'est pratique pour un client qui scanne avec l'appareil photo de son téléphone, mais attention : si le lien pointe vers le logiciel d'un prestataire, il peut ne plus rien afficher le jour où vous changez d'outil.

💡 Notre recommandation — Un identifiant court et unique, imprimé aussi en clair sous le QR code. C'est simple, durable, et ça reste lisible par un humain si le code est illisible.

Bien choisir et poser les étiquettes

  • Un QR code standard, pas un « Micro QR » : les petits Micro QR ne sont pas lus par la plupart des téléphones.
  • Une taille d'au moins 2 × 2 cm pour le QR code lui-même, avec une marge blanche autour : c'est elle qui permet au téléphone de le repérer.
  • Un support résistant : étiquette polyester ou vinyle, laminée, qui supporte l'humidité, les UV et les produits de nettoyage. Le papier ne tient pas en extérieur ni en cuisine.
  • Le même emplacement sur tous les appareils, sur le corps de l'extincteur, côté visible, à hauteur de main : le technicien ne doit pas tourner l'appareil pour scanner.
  • Le numéro imprimé en clair sous le code, pour les cas où le scan ne passe pas.
  • Si l'étiquette contient du texte accentué (« Année », « N° »), demandez à votre imprimeur un encodage UTF-8 : c'est le format lu correctement par tous les téléphones.

Reprendre les étiquettes d'un ancien prestataire

Bonne nouvelle : quand vous reprenez un site, vous n'êtes pas obligé de réétiqueter. Si les appareils portent déjà des QR codes lisibles, il suffit d'associer le contenu de chaque code à la fiche de l'appareil dans votre logiciel. La plupart des logiciels permettent de le faire en important le fichier d'équipements du client, avec une colonne « QR code ».

Vérifiez simplement deux choses avant de vous engager :

  1. Ce que contiennent les codes : scannez-en quelques-uns avec l'appareil photo de votre téléphone. Un numéro ou des caractéristiques, c'est parfait. Un lien vers le logiciel de l'ancien prestataire, ça marche aussi, tant que chaque lien est unique.
  2. Le type de code : un vrai QR code (petit carré avec trois repères dans les coins). Les codes-barres classiques et les « Data Matrix » demandent un lecteur adapté.

Faire l'inventaire d'un site en scannant

Le cas le plus fréquent : un nouveau client, des appareils étiquetés, mais aucun fichier d'équipements à importer. Plutôt que de tout saisir à la main, on construit le parc pendant la première visite :

  1. Le technicien scanne l'étiquette d'un appareil inconnu.
  2. La fiche « nouvel équipement » s'ouvre, déjà remplie : avec les informations du QR code s'il en contient, sinon avec celles de l'appareil précédent (famille, type, marque, zone). Le numéro suivant est proposé automatiquement.
  3. Il vérifie, valide, fait son contrôle, et passe à l'étiquette suivante.

À la fin de la tournée, le parc du site est entièrement constitué, et la visite suivante se fera en un scan par appareil.

Les erreurs à éviter

  • Mettre deux fois le même code sur deux appareils : chaque étiquette doit être unique, sinon le scan ouvre le mauvais extincteur.
  • Encoder un lien vers un outil que vous ne maîtrisez pas : le jour où l'outil change, toutes les étiquettes deviennent inutiles.
  • Choisir des étiquettes trop petites pour gagner de la place : un code illisible fait perdre plus de temps qu'il n'en fait gagner.
  • Oublier de mettre à jour la fiche quand un appareil est remplacé : la nouvelle étiquette doit être associée au nouvel appareil, et l'ancien passé en « retiré ».
  • Compter uniquement sur le scan : gardez toujours le numéro en clair et une recherche par numéro dans votre logiciel, pour les étiquettes abîmées.

Questions fréquentes

Le QR code sur les extincteurs est-il obligatoire ?

Non. Ce qui est attendu, c'est que chaque appareil soit identifié (numéro, emplacement) et que ses vérifications soient tracées dans le registre de sécurité. Le QR code est un moyen pratique et fiable de le faire, pas une obligation.

Faut-il installer une application pour scanner les étiquettes ?

Pas forcément. Avec un logiciel web comme Firovia, le scan se fait directement dans le navigateur du téléphone : il suffit d'autoriser l'accès à la caméra la première fois.

Peut-on garder les étiquettes posées par un ancien prestataire ?

Oui, si ce sont des QR codes lisibles et uniques. Il suffit d'associer le contenu de chaque code à la fiche de l'appareil, par import d'un fichier ou au fil des scans pendant la première visite.

Que faire si une étiquette est abîmée ou illisible ?

Retrouvez l'appareil par son numéro (imprimé en clair sous le code ou noté sur le plan), faites le contrôle, puis posez une nouvelle étiquette et associez son code à la fiche de l'appareil.

QR code ou code-barres classique ?

Le QR code : il se lit sous tous les angles, contient plus d'informations et reste lisible même partiellement abîmé grâce à sa correction d'erreur. Le code-barres classique demande d'être bien aligné et ne contient qu'un numéro.
